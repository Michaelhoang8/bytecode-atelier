        Files & language guide
        

          
        

        

          Declare a variable with let count = 3;, change it with
          count = count + 1;, and display it with print count;. Names are
          case-sensitive.
        

        

          Decimal arithmetic uses JavaScript numbers, bounded to ±1e12. Division returns a decimal;
          % is remainder. No loops, functions, strings, or network access. Source limit: 32,000
          characters; 4,000 tokens; 256 statements.
